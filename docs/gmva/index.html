Generic Model of Value Addition

See the whole organization as a system of value addition.

GMVA is an industry-independent way to describe organizational structure, economic activity and value creation as one connected model.

SQL changed how we structure data beyond spreadsheets.

GMVA does the same for the whole organization.

01 / Simplest form

One economic relationship.

Income
−
Purchase Costs
−
Refining
=
Profit / Loss

Every Function can be treated as an economic summarizer. Functions combine into the organization, which is the larger summarizer.

02 / Two dimensions

Functions and Product Build Scope are independent.

Functions

Describe what the organization does and where activities, resources and economic results belong.

Product Build Scope

Describes how the organization's product or service is built, including multiple instances and branches.

The two structures meet through participation. They should not be collapsed into one hierarchy.

03 / Evaluation rule

A Function's own Profit/Loss is never the evaluation target.

A Function may deliberately consume resources while enabling value elsewhere. The meaningful evaluation target is the result of the organization as a whole.

04 / Origin

From hosting business to a generic model.

GMVA grew from observations of IT service business beginning in 1999 and was first presented on 15 August 2001. The hosting-business work was a practical starting point; the model itself is intended to be industry-independent and can also describe non-profit organizations.

# VIEPS Deployment Knowledge

## Execution evidence recording

Actual VIEPS deployment execution evidence is durable project history and belongs in the relevant GitHub Issue or Pull Request record.

Use the canonical execution-task result template:

`3-Deployment/internet/jagports/solution/vieps/deployment_ExecutionTaskResultTemplate.md`

The template is the minimum recording structure for each actual execution task. Do not invent a separate comment format when recording a task result.

Execution and verification are distinct states. A successful command or UI action is execution evidence; verification must record the evidence that establishes the resulting state.

Deployment Markdown documents define procedures and reusable knowledge. They are not a duplicate execution log when the actual task evidence belongs in GitHub Issue/PR history.

Historical execution records must remain chronological. Existing closed Issue/PR descriptions and comments are not rewritten merely to retrofit a later recording standard.

Never record passwords, tokens, recovery codes, credentials, secret values, or other sensitive authentication material in repository content or GitHub Issue/PR records.

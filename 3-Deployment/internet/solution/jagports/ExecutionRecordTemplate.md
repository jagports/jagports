# Execution Record Template

Use this template for actual deployment execution evidence. Do not record credentials or secret values.

```text
Date/time:
Operator:
Task:
Environment:
Resource:
Interface: CLI | API | UI
Command / dashboard path:
Expected result:
Observed result:
Status: RESEARCHED | EXECUTED | VERIFIED | BLOCKED | FAIL | NOT RUN
Verification command / evidence:
Deviation / decision:
```

## Rules

- Record actual execution, not planned execution.
- Record verification separately from execution.
- Keep task-specific evidence with the relevant GitHub Issue/PR where appropriate.
- Never record passwords, password hashes, recovery codes, API tokens, credentials, or secret values.

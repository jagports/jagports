# 3-Deployment

Deployment knowledge and related deployment processes belong in this area.

## Placement rule

- `5-Products-projects/` contains product/project development.
- `3-Deployment/` contains production deployment knowledge and related deployment processes.
- `4-Production/` contains production runtime and implementation components.
- `4-Production/base/` is the production foundation.
- Do not create additional root folders.
- If the correct deployment subfolder is unclear, ask the Product Owner rather than inventing a structure.

## Current deployment foundation

The MVP deployment target uses the **GitHub + Cloudflare Free** foundation. Deployment knowledge and procedures for that foundation belong here; the corresponding production foundation implementation belongs under the appropriate `4-Production/base/` location.

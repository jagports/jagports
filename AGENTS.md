# Jagports AI OS — Agent Instructions

## Before Beginning Work

Before beginning work on any GitHub Issue, inspect all eight root folders, including empty folders. Use their names as the first-level semantic map to identify the domains relevant to the Issue.

- `0-DocumentationEducationCompetense` — Documentation, education, competencies, and agent protocol.
- `00-Management` — Repository and project management; performed by human `tlindi`.
- `2-Sales` — Sales, customers, and commercial matters.
- `3-Deployment` — Deployment, installation, and operational deployment.
- `4-Production` — Production data and files, organized as `Base → Platform → Platform Application → Application → EndCustomer`. There is currently no production data or code.
- `5-Implementation-Projects` — Active implementation projects.
- `6-Development` — Software, engineering, and technical development.
- `7-Research` — Research, investigation, evidence, and verification.

## Documentation Discovery

`KNOWLEDGE.md` is the designated filename for repository or domain knowledge. After identifying the relevant domains, read `KNOWLEDGE.md` in those domains when present. Do not read other Markdown files as part of general knowledge discovery unless a separate instruction explicitly requires them.

When applicable, also check:
- `7-Research` for research, evidence, investigation, or verification.
- `00-Management` and `4-Production` for management, governance, requirements, priorities, production, or product decisions.
- `5-Implementation-Projects` and `6-Development` for implementation work.

If relevant documentation conflicts, follow the established authority/decision rules. If the conflict cannot be resolved, escalate it as `CONFLICT` before proceeding with the affected decision or change.

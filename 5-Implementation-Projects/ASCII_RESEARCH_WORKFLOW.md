# Project Research Workflow

This file contains the reusable visual explanation for the research-to-implementation process. It belongs with implementation-project knowledge rather than the repository-wide knowledge index.

```text
Research
   ↓
Finding
   ↓
Opportunity
   ↓
Feature Proposal
   ↓
Prioritization
   ↓
Decision
   ↓
Approval
   ↓
Implementation
```

Use this diagram when explaining how research becomes an approved implementation task. Keep task-specific Issue and PR numbers in the relevant task record, not in this reusable diagram.

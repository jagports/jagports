SKILL.md
  Input:
    - Project knowledge.md
    - prioritized task list
    - GitHub repository
    - GitHub Project

  Procedure:
    1. Inspect repository and existing Project.
    2. Identify already completed tasks.
    3. Never duplicate existing Issues.
    4. Create one Issue per remaining task.
    5. Preserve explicit P1, P1.1, P1.2 ordering.
    6. Set Executor and Where.
    7. Add Issues to the Project.
    8. Set correct Kanban status.
    9. Verify every task exists exactly once.
    10. Report discrepancies/errors.

  Rules:
    - Kanban setup is always first.
    - No arbitrary parallel P0/P1 priorities.
    - Sub-priorities are allowed.
    - Human approval is required for DECISION items.
    - GitHub is the communication/system-of-record layer.
    - Stay within the $0 architecture.
